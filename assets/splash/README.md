# Assets - Native Splash Screen

Letakkan file logo splash screen di folder ini sesuai nama berikut:

1. `splash_logo.png` (Logo Splash Mode Terang):
   - **Ukuran**: 1024 x 1024 px (atau 512 x 512 px)
   - **Format**: PNG Transparan (logo di area tengah dengan proporsi pas)
   - **Background**: Putih (`#FFFFFF` dikonfigurasi otomatis di native splash).

2. `splash_logo_dark.png` (Logo Splash Mode Gelap / Dark Mode):
   - **Ukuran**: 1024 x 1024 px (atau 512 x 512 px)
   - **Format**: PNG Transparan (logo versi terang/kontras untuk background gelap)
   - **Background**: Deep Navy / Dark Slate (`#0F172A` dikonfigurasi otomatis).
